# sito-gc

File del sito gianlucontent.com, caricati dalle pagine GoHighLevel con `loader.js`.
Pubblicati con GitHub Pages: https://gianlucontent.github.io/sito-gc/

Non modificare a mano: i file vengono generati dal Second Brain
(`07_Progetti/Sito GianluContent/ghl/build_ghl.py`, cartella `pubblica/`).

| File | Pagina GHL |
| --- | --- |
| `home.html` | Home (`data-page="home"`) |
| `brief.html` | /brief-formazione (`data-page="brief"`) |
| `loader.js` | Caricatore incollato una sola volta in GHL |
| `img/` | Foto del sito (AVIF + WebP) |
